# 시아·아윤이 루틴 보드

시아·아윤이가 스스로 공부 루틴과 생활 루틴, 일정을 체크하고 도장을 모으는 보드예요. 엄마·아빠는 칭찬 별과 채팅으로 함께해요.

## 화면

- **홈** — 시아·아윤이 카드(공부/생활 루틴 진행, 연속 일수, 오늘·누적 도장, 주간 도장판, 오늘의 미션, 오늘 할 일)
- **루틴** — 아이별 공부 루틴 · 생활 루틴 체크, 항목 추가/수정/고정, 집중 타이머
- **일정** — 아이별 오늘 일정과 앞으로 일주일 일정(학원·학교·숙제·준비물 태그와 필터)
- **칭찬** — 칭찬 별·도장 보내기, 도장 적립 내역, 도장 달력
- **채팅** — 가족 말풍선·스티커·하트

도장은 치이카와 얼굴 도장, 캐릭터는 시아=우사기 · 아윤이=시사예요. 엄마·아빠에게는 도장·루틴·일정이 없고 칭찬과 채팅만 있어요.

## 실시간 공유

- 기록은 기기의 `localStorage`에 먼저 저장되고, Firebase 실시간 데이터베이스(`families/fam_880716_k9x3m7/state`)와 이어져 가족 모두의 화면에 바로 나타나요.
- 인터넷이 없을 때도 그대로 쓸 수 있고, 다시 이어지면 쌓인 기록이 자동으로 올라가요. 헤더의 작은 표시(🟢 실시간 / 🟠 로컬)로 연결 상태를 볼 수 있어요.
- 이 기기에서 고른 '지금 보는 사람'과 '이 기기 잠금' 설정은 그 기기에만 남아요.
- 예전 기록(식사·건강 화면, 엄마·아빠 루틴/도장)은 열 때 조용히 정리되고, 공부 루틴만 있던 기록에는 생활 루틴이 한 번만 채워져요.

## 다른 방으로 열기

주소 뒤에 `?room=방이름`을 붙이면 다른 방으로 열려요. (예: `index.html?room=our-room`)

## 구성

- `index.html` — 스타일과 스크립트를 하나로 합친 단일 파일. 이 파일 하나만 있으면 동작해요.
- 빌드 원본은 `_src/`(index.html · style.css · app.js)이고, `python3 build.py`로 다시 합쳐요.
- `_src/tests/` — 화면 없이 기능 전체를 돌려 보는 검사(QuickJS 기반, 실제 Firebase 대신 가짜 SDK 사용).
