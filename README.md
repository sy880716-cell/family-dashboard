# 우리 가족 기록장

가족이 함께 쓰는 포근한 기록장이에요. 루틴·할 일·식사·건강·칭찬 도장·가족 채팅을 한 화면에서 기록해요.

## 실시간 공유

- 기록은 기기의 `localStorage`에 먼저 저장되고, Firebase 실시간 데이터베이스와 이어져 가족 모두의 화면에 바로 나타나요.
- 인터넷이 없을 때도 그대로 쓸 수 있고, 다시 이어지면 쌓인 기록이 자동으로 올라가요. 헤더의 작은 표시(🟢 실시간 / 🟠 로컬)로 연결 상태를 볼 수 있어요.
- 이 기기에서 고른 가족과 '이 기기 잠금' 설정은 그 기기에만 남아요. 엄마 휴대폰은 늘 엄마로, 아빠 휴대폰은 늘 아빠로 기록돼요.

## 다른 방으로 열기

주소 뒤에 `?room=방이름`을 붙이면 다른 방으로 열려요. (예: `index.html?room=our-room`)

## 구성

- `index.html` — 스타일과 스크립트를 하나로 합친 단일 파일. 이 파일 하나만 있으면 동작해요.
- 빌드 원본은 `_src/`(index.html · style.css · app.js)이고, `python3 build.py`로 다시 합쳐요.
- `_src/tests/` — 화면 없이 기능 전체를 돌려 보는 검사(QuickJS 기반, 실제 Firebase 대신 가짜 SDK 사용).
